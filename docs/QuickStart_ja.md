# MORPHASE クイックスタートガイド

**MORPHASE** は、M5Stack **Cardputer ADV** 用の **4 オペレータ FM ポリフォニック・シンセサイザー**のファームウェアです。MIDI キーボードで弾き、Cardputer は音色を作るエディタとコントローラとして使います。本体を傾けたり、手をかざしたりして、音を動かすこともできます。

このガイドは、電源を入れてから最初の音を出し、主な機能を一通り体験するまでを短くまとめたものです。すべての項目の詳しい説明は「リファレンスガイド」を参照してください。

---

## 1. 準備するもの

| もの | 内容 |
|---|---|
| **Cardputer ADV** | オリジナルの Cardputer（ADV でない方）には対応していません |
| **microSD カード** | FAT32。パッチや設定の保存先です |
| **MIDI キーボード** | 次のどちらかでつなぎます |
| └ 通常版 | M5Stack **Unit MIDI**（U187）を本体の Grove 端子に挿して、5 ピンの MIDI ケーブルでキーボードとつなぐ |
| └ BLE 版 | iPhone / iPad などの、Bluetooth MIDI を送れるアプリやキーボード（Unit MIDI も使えます）。動作を確かめたアプリ: [KeyPad](https://www.discodsp.com/jp/keypad/) |
| **イヤホン** | おすすめ。本体のスピーカーでは低い音がほとんど聞こえません |

MORPHASE には **通常版** と **BLE 版** の 2 つがあります。違いは、Bluetooth MIDI を受けられるかどうかと、同時に鳴らせる音の数です。

| | 通常版 | BLE 版 |
|---|---|---|
| MIDI | Unit MIDI（DIN） | Unit MIDI（DIN）+ Bluetooth MIDI |
| 同時に鳴らせる音 | 12 音 | 10 音 |

どちらを入れたかは、起動画面と `SET > Info` の版の表示で分かります（BLE 版は ` BLE` が付きます）。

## 2. 起動する

microSD カードを挿して電源を入れます。

**初めて起動したとき**は、カードに `/MORPHASE` フォルダが作られ、**32 個のファクトリーパッチ**（あらかじめ用意された音色）と、2 本のファクトリーのチェーン（あとで説明します）が書き込まれます。数秒かかります。

起動画面のあと、**PLAY 画面**が表示されます。ここが MORPHASE の「ホーム画面」です。

![PLAY 画面](images/screens/play.png)

| 場所 | 表示されるもの |
|---|---|
| 一番上 | パッチの名前（大きな文字）、一覧の何番目か（例 `1/32`）、アルゴリズムと鳴っている音の数（例 `Algo 5  0/12`） |
| その下の列 | 鳴っている音の名前（声ごとの枠。ARP が On のときは ARP の和音） |
| 左の中央 | 出力の波形（スコープ）。その上に GMorph・Feedback の値、FX の文字（`C D R X V`）、`GL`、チェーンの状態など |
| 左の下 | ピッチベンドのバー、ARP と LFO の状態、`MIDI` `HOLD` `OCT` `TRN` `THR` の印 |
| 右の列 | 傾き（IMU）のパッドと X / Y の状態、傾きの行き先、本体の音量（`VOL`） |

画面の上には、`PLAY` `OP` `ALGO` `ARP` `LFO` `FX` `SET` のタブが並んでいます。

## 3. つなぐ

### 通常版（Unit MIDI）

1. Unit MIDI の DIP スイッチを **BYPASS** に、本体の Grove の 5V スイッチを **5VOUT** にします
2. Unit MIDI を本体の Grove 端子（G1 / G2）に挿し、MIDI キーボードの MIDI OUT とつなぎます
3. 鍵盤を弾いて、PLAY 画面の左下の **`MIDI`** が点けば受信できています

受信チャンネルは、最初は **Omni**（すべてのチャンネル）です。

### BLE 版（Bluetooth MIDI）

1. 本体の電源を入れると、`MORPHASE` という名前で Bluetooth MIDI の相手を待ちます。PLAY 画面の名前の右に、暗い **`b`** が出ます
2. iPhone / iPad の **アプリの中**（Bluetooth MIDI の接続画面）から `MORPHASE` を選びます。スマートフォンの「設定」の Bluetooth の画面からではありません
3. つながると、明るい **`B`** に変わります

![BLE 版の PLAY 画面（名前の右に B）](images/screens/play_ble.png)

## 4. 最初の音を出す

鍵盤を弾いてみてください。最初は `01_EPiano`（エレクトリック・ピアノ）が鳴ります。強く弾くほど、明るく大きな音になります。

### パッチ（音色）を選ぶ

- **本体で**: `Tab` を何回か押して **SET** タブへ → `Patch` で `Enter` → `Load` で `Enter` → `;` `.` で選んで `Enter`
- **MIDI で**: キーボードからプログラムチェンジ 0〜31 を送ると、01〜32 のファクトリーパッチが選ばれます

### まず弾いてほしい 5 つ

| パッチ | どんな音か |
|---|---|
| `01_EPiano` | エレクトリック・ピアノ。弾く強さで表情が変わる |
| `04_Organ` | オルガン。押している間ずっと鳴る |
| `13_MorphLd` | 単音のリード。本体を傾けると音色が変わる（次の章） |
| `23_TiltPad` | 広がりのあるパッド。傾けると音色が動く |
| `25_Kick` | バスドラム。C1〜C2 あたりの低い鍵盤で |

### 基本のキー

| キー | 内容 |
|---|---|
| `K` / `L` | 音量を下げる / 上げる（押し続けると続けて変わる） |
| `;` / `.` | オクターブを上げる / 下げる（PLAY 画面） |
| `,` / `/` | トランスポーズ（半音ずつ、PLAY 画面） |
| `Z` / `X` | 押している間、ピッチベンド（下げる / 上げる） |
| `D` | ノートホールド（もう一度押すまで、押さえた音を伸ばす） |
| `Shift+H` | その画面のヘルプを出す / 消す |
| `G0`（本体の G0 ボタン） | PLAY 画面と、最後に開いた編集のタブを行き来する |

![PLAY 画面のキー配置図](images/play_keymap_ja.svg)

## 5. 本体を傾けてみる

Cardputer ADV には傾きのセンサー（IMU）が入っています。**最初は Off** なので、まず On にします。

| キー | 内容 |
|---|---|
| `Shift+A` | X 軸（左右の傾き）を On / Off |
| `Shift+S` | Y 軸（前後の傾き）を On / Off |
| `A` / `S` | その軸の今の傾きを固定（ホールド）/ 解除 |

On にして傾けると、たいていのパッチで、**X 軸で音色（波形）が、Y 軸で音のざらつき（フィードバック）が**変わります。`13_MorphLd` や `23_TiltPad` のように、傾けたときの動きを作り込んであるパッチもあります。`32_Drone` は、傾けると音が崩れていきます。

![SET > IMU](images/screens/imu.png)

傾きで何を動かすかは、`SET > IMU` の `XTarget` / `YTarget`（行き先）と `XDepth` / `YDepth`（深さ）で変えられます。

## 6. FX を足し引きする

MORPHASE には 5 つのエフェクトがあります（Chorus / Delay / Reverb / Crush / Drive）。演奏しながら、次のキーで一時的に入れたり外したりできます。

| キー | エフェクト | PLAY 画面の文字 |
|---|---|---|
| `q` | Chorus（揺れと広がり） | `C` |
| `w` | Delay（やまびこ） | `D` |
| `e` | Reverb（残響） | `R` |
| `r` | Crush（デジタルの粗さ） | `X` |
| `t` | Drive（歪み） | `V` |

パッチで使っているエフェクトは一時的に外れ、使っていないエフェクトは一時的に加わります。この切り替えは保存されず、パッチを読み込み直すと元に戻ります。

**MORPHASE は、歪み系のエフェクト（Drive・Crush）を使わなければ歪みません。** 音が大きすぎるときは、最後にある「出力のリミッター」が音量だけを下げて、割れを防ぎます。

### GLITCH（わざと崩す）

`g` を押している間、音がランダムに崩れます（同じ所をくり返す・逆回し・ぶつ切り・音色が一瞬飛ぶ、など）。崩し方は `SET > Glitch` で選べます。

## 7. 音を少し変える

MORPHASE の音は、**4 つのオペレータ（OP）**の組み合わせでできています。オペレータは、それぞれが 1 つの波形を鳴らす小さな発振器です。

- **キャリア**: 実際に聞こえる音を出すオペレータ
- **モジュレータ**: キャリアの波形を揺らして、音色を変えるオペレータ（耳には直接聞こえない）
- **Ratio（比率）**: 弾いた音の何倍の高さで鳴るか

**OP タブ**で試してみましょう。

1. `Tab` で OP タブへ。数字キー `1`〜`4` でオペレータを選びます（画面に `CARRIER` か `MODULATOR` と出ます）
2. `;` `.` で項目を選び、`,` `/` で値を変えます（押し続けると 10 倍の幅で動きます）
3. モジュレータの **`Level`** を上げ下げすると、音の明るさが大きく変わります
4. **`Morph`** を動かすと、そのオペレータの波形が、なめらかな正弦波からとがった波形へ変わっていきます
5. **`A` `D` `S` `R`** の行に来ると、エンベロープ（音の立ち上がりと消え方）のグラフが出ます。鍵盤を押すと、白い点がグラフの上を進みます

![OP タブのエンベロープのグラフ](images/screens/op_env.png)

どれだけ変えても、保存しなければファクトリーパッチは元のままです。

## 8. パッチを保存する

`SET > Patch` で保存します。

- **Save**: 今のパッチに上書き（確認が出ます）
- **SaveAs**: 名前を付けて保存（12 文字まで、英数字と `-` `_` `.`）

ファクトリーパッチ（`01_` のように数字で始まるもの）は**上書きできません**。Save を選ぶと、別の名前で保存する画面になります（例: `01_EPiano` → `EPiano2`）。間違って消したり変えたりしても、`SET > Patch > Factory` で全部元に戻せます。

## 9. モーフを体験する

MORPHASE の名前の由来の機能です。パッチからパッチへ、音をなめらかに移していきます。

1. `SET > Patch > Morph` を開きます（題名 `MORPH > Slots`）。8 つのスロットにパッチが並んでいます（最初は「Pads」のチェーン）
2. `Shift+1`〜`Shift+8` を押すと、今の音からそのスロットのパッチへ、`Time`（最初は 1 秒）かけて移ります。PLAY 画面に `M>3 45%` のように出ます
3. ドラムで試すなら、`Chains >` を開いて `02_Drums` を Load します（スロット 1 = `25_Kick`、2 = `26_Tom`）

![MORPH > Slots](images/screens/morph_slots.png)

**つながりがなめらかなのは、同じアルゴリズム（オペレータのつなぎ方）のパッチどうし**です。アルゴリズムが違うと、途中で音が切り替わります。

MIDI キーボードのパッドで切り替えたいときは、`SET > MIDI > PC Mode` を `Morph` にすると、プログラムチェンジ 0〜7 でスロット 1〜8 へ移ります。

## 10. MORPHASE でできること

ここまでで触れた機能も含めて、MORPHASE でできることの全体です。

**FM シンセのエンジン**
- **4 オペレータの FM 音源、14 種類のアルゴリズム**：4 オペレータ FM の定番の形を中心にした 8 種類に加え、フィードバックの位置が違う 6 種類（のこぎり波・うなり・金属の音向け）
- **波形のモーフ**：オペレータごとに、正弦波からとがった波形まで 8 つの波形の間をなめらかに移り変わる。`GMorph` で 4 つまとめて動かせる
- **固定周波数のオペレータとピッチエンベロープ**：キック・タム・金物など打楽器も作れる
- **12 音ポリフォニック**（BLE 版は 10 音）。モノ・レガート・グライドも

**パッチモーフ：音から音へ**
- 8 つのスロットに並べたパッチの間を、比率もエンベロープも FX もまるごと混ぜながら移っていく
- ノブ・傾き・LFO で「位置」を動かすチェーンと、`Shift+1〜8` や MIDI のパッドで狙ったパッチへ滑っていくグライドの 2 通り
- 並べたチェーンは名前を付けて保存でき、MIDI のボタンで次々に切り替えられる

**GLITCH：わざと崩す**
- 直前の音をくり返す・逆回し・ぶつ切り（Stutter / Reverse / Gate）
- 音色を一瞬飛ばす（Chaos）
- アルペジオの刻みを崩す（打ち直し・オクターブ跳び・逆行・休符）
- `g` を押している間だけ、常に、本体を傾けたぶんだけ、のどれでも起こせる

**テルミン（M5Stack Unit ToF4M 対応）**
- 距離センサーに**手をかざして**音を動かす
- 手の距離で音色などを動かす `Mod` と、手の高さで 1 音を弾く楽器になる `Play` の 2 つのモード。`Play` では、なめらかな音程のほか、49 種類のスケールに合わせることもできる
- 鍵盤と同時に弾ける（左手で和音、右手でテルミン）

**体で動かす**
- **本体を傾けて**音色を変える（IMU。On にするだけで、たいていのパッチで効く）
- MIDI コントローラーのノブ 4 つ・ボタン 4 つを、動かすだけで覚えさせる（MIDI Learn）

**アルペジエーター**
- 5 つのパターン（Up / Down / UpDown / Random / AsPlayed）+ **STEP**：16 ステップに「押さえた和音の何番目の音か」を並べるので、和音を変えるとリズムはそのまま音だけが変わる
- ラッチ、スウィング、外部 MIDI クロックへの同期、パターンを 8 つ保存

**FX と、歪まない出力**
- Crush・Chorus・Delay・Reverb・Drive。`q w e r t` で演奏しながら抜き差し
- 最後に出力のリミッター：大きな和音でも、波形を曲げずに音量だけを抑える

**すぐ鳴らせる 32 個のファクトリーパッチ**
- 鍵盤・ベル・ベース・リード・パッド・ドラム・ノイズまで

**2 つの版**
- 通常版（Unit MIDI）と、iPhone / iPad から Bluetooth MIDI でも弾ける BLE 版（動作を確かめたアプリ: [KeyPad](https://www.discodsp.com/jp/keypad/)）

## 11. もっと知りたくなったら

リファレンスガイドに、次のような機能の説明があります。

- 14 種類のアルゴリズム、固定周波数のオペレータ、ピッチエンベロープ

## 12. 困ったときは

### まずヘルプを

どの画面でも、`Shift+H` でその画面のキーの一覧が出ます。もう一度 `Shift+H` で消えます。

![PLAY 画面のヘルプ](images/screens/help.png)

### 音が出ない

- 本体の音量（PLAY 画面の右下の `VOL`）が 0 になっていないか。`L` で上げます
- MIDI を受けているか。鍵盤を弾いて `MIDI` が点くか見ます。点かないときは、Unit MIDI の向き・DIP スイッチ（BYPASS）・Grove の 5V スイッチ（5VOUT）を確かめます
- 受信チャンネル（`SET > MIDI > Channel`）が、キーボードの送信チャンネルと合っているか（最初は Omni）
- microSD カードが入っているか（カードが無くても初期の音は鳴りますが、何も保存されません）

### キーボード（本体のキー）が反応しなくなった

ごくまれに、キーを速く打ったときなどに、本体のキーが一切反応しなくなることがあります。これは Cardputer ADV のキーボードのチップ（TCA8418）が持つ、ハードウェアの既知の癖です。**MORPHASE はこれを見つけて、30 秒ほどで自動的に再起動します。** そのままお待ちください。

### BLE 版がつながらない

- アプリの中から接続していますか（スマートフォンの「設定」の Bluetooth 画面では MIDI はつながりません）
- 以前、同じ Cardputer を別のファームウェアで Bluetooth 機器として登録したことがあるなら、スマートフォンの Bluetooth の設定から、その古い登録を解除してください
- `SET > MIDI > BLE` が `On` になっているか（変えたら再起動が必要です）

### それでも解決しないとき

GitHub の Issue か、開発者（@Tokagetchi）までご連絡ください。
